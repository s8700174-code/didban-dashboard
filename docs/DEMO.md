# معرفی دیدبان به کارفرما

## متن کوتاه قابل استفاده

«برای نمایش رویکرد طراحی و پیاده‌سازی داشبورد، نمونه مستقل دیدبان را آماده کرده‌ام. در این دمو می‌توانید فیلتر دوره و واحد، شاخص‌های محاسبه‌شده، گزارش‌های ماهانه، پایش پروژه و خروجی CSV را امتحان کنید. داده‌ها کاملاً آزمایشی هستند و این نمونه سفارش قبلی مشتری نیست. برای پروژه شما، اتصال داده، نقش کاربران و معیارهای پذیرش پس از بررسی نیاز واقعی تعیین می‌شود.»

دمو: https://s8700174-code.github.io/didban-dashboard/

کد و توضیحات: https://github.com/s8700174-code/didban-dashboard

## نمایش دو دقیقه‌ای

1. نمای کلی: درآمد، هزینه و سود نمونه از یک منبع داده محاسبه می‌شوند.
2. فیلتر «شهریور» و «فروش»: اعداد ۳۱۱، ۱۶۶ و ۱۴۵؛ نمودار و جدول هماهنگ تغییر می‌کنند.
3. بازطراحی مسیر فروش: مقایسه بودجه مصرف‌شده و پیشرفت و نمایش مراحل تحویل.
4. پروژه‌ها: جست‌وجوی شناسه `DB-102` و فیلتر وضعیت؛ افزودن به پیگیری محلی.
5. گزارش عملکرد: جدول قابل بررسی و خروجی CSV متناسب با فیلتر.
6. نمایش موبایل و حالت تیره.

در ارائه، ساختگی‌بودن داده‌ها و نبود بک‌اند تولیدی را روشن بیان کنید. هیچ سابقه، رضایت مشتری، گواهی یا تضمین عملکرد واقعی از این نمونه استنباط نشود.
