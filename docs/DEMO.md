# Introducing Didban to clients

## Short introduction

Didban is an independent portfolio demo showing how business data can become a clear executive dashboard. Try period and business-unit filters, calculated KPIs, monthly reports, project tracking and CSV exports. All data is synthetic. For a client project, data integrations, user roles and acceptance criteria would be defined after reviewing the actual requirements.

[Live demo](https://s8700174-code.github.io/didban-dashboard/) · [Source and documentation](https://github.com/s8700174-code/didban-dashboard)

## Two-minute walkthrough

1. Open the overview: revenue, operating cost and illustrative profit are calculated from the same dataset.
2. Select Shahrivar and Sales: revenue is 311, cost is 166 and profit is 145 million toman. The chart and table update together.
3. Open the sales-process redesign project: compare budget consumption with progress and review delivery milestones.
4. Visit Projects: search for `DB-102`, apply a status filter and bookmark the project in browser storage.
5. Visit Performance Reports: inspect monthly figures and export a CSV matching the current filters.
6. Demonstrate the responsive mobile layout and dark theme.

## Scope to explain

This is a front-end demonstration with synthetic data and no production backend. It does not establish client history, testimonials, certifications or guaranteed business outcomes. Production data sources, authentication, permissions and deployment requirements must be scoped separately.
